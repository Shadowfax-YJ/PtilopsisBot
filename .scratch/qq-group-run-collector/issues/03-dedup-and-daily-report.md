# 去重和每日贡献统计

Type: task
Status: implemented; live acceptance pending

## 实现

- 同一个源群文件只算一次上传；不同源文件都算上传，即使名称或内容相同。上传次数只涵盖通过准入并登记的对局包，不含群里的其他文件。
- 完整 ZIP 的 SHA-256 相同就算同一个唯一包，不拆包做语义去重。新增贡献归机器人首次收集成功的上传记录；成功时间相同按记录 ID 排序。后续相同内容的上传只增加上传次数，不增加唯一包数。
- 次日 00:05 按 Asia/Shanghai 的前一自然日及 QQ 上传时间汇总，发回配置的群。按上传者 QQ 号汇总，显示最新昵称；按新增唯一包数降序，同数按 QQ 号排序即可。
- 每人只列上传次数、新增唯一包数；末尾给出当日全群待处理、检查不通过和处理失败数。ZIP 检查阶段注明“仅检查 ZIP 可读性，未验证游戏内容”，真实业务检查接入后再更新说明。
- 从 SQLite 当前记录生成日报，不做日报快照、修订历史或自动补报。提供本机重发指定日期日报的入口；迟到完成或补扫修正上传日期后，手动重发即可。
- 发送失败记日志，收集照常；离线错过的日报也手动补发，不另做消息投递队列或送达确认。

## 完成标准

两个成员上传相同包时，各有一次上传，只有首次收集成功的一方得到一个新增唯一包。跨午夜、检查失败和手动重发的统计符合以上口径。
