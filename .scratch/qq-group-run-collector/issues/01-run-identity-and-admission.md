# 识别上传并登记

Type: task
Status: implemented; live acceptance pending

## 实现

- 只接收配置的 QQ 群，文件名精确匹配 `^run-\d{8}-\d{6}-\d{6}\.zip$`，日期时间能解析，声明大小为 1 byte 到 256 MiB。上限可配置；不符合条件的文件忽略即可。
- 用 `(group_id, file_id, busid)` 唯一标识源群文件。事件和补扫重复发现时更新同一条 SQLite 上传记录；同名重传仍是新记录。
- 保存上传者 QQ 号、显示昵称、QQ 上传时间、原文件名、声明大小、对局时间和处理结果。日报按 QQ 上传时间归日；补扫有 `upload_time` 就采用它，否则使用事件时间。
- 对局时间按 Asia/Shanghai 解析，最后六位是微秒。与上传时间相差多久都不拦截，不另建偏差诊断流程。
- 首次发现写入待处理记录后再下载。缺少源文件身份或上传者时记一条日志，交给下次补扫补齐；不建立原始事件档案和冲突状态。
- 昵称和上传时间可以由补扫补齐；已登记的上传者、文件名或大小出现冲突时记日志并保留原值，不另下载多个版本。
- 根目录是主动补扫范围；事件没有目录信息时直接接收符合条件的包，不承诺嵌套目录补漏。

## 完成标准

同一上传重复通知或被补扫发现，只登记和下载一次；不同源文件即使同名也各留一条上传记录。错群、错误名称或超限文件不进入下载流程。
